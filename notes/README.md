# 学习笔记

放 C 语言、STM32、FreeRTOS、通信协议等知识点的总结。

## 建议命名

- `c-pointer.md` - 指针深度笔记
- `c-macro.md` - 宏 / 预处理笔记
- `stm32-gpio.md` - GPIO 配置笔记
- `stm32-uart.md` - UART 驱动笔记
- `freertos-task.md` - FreeRTOS 任务调度笔记
- `protocol-spi.md` - SPI 协议笔记

## 写笔记的好处

1. **复习比看书快 3 倍** —— 自己写过的最好记
2. **面试时翻一翻** —— 任何细节都能秒答
3. **GitHub 上是个人作品集** —— 面试官能看到 K 的学习痕迹

## 格式建议

每个笔记包含：
- 一句话定义
- 关键知识点（带代码示例）
- 易错点（K 自己踩过的坑）
- 参考资料
