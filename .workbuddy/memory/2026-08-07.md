### Bug 修复：install-autosync.ps1 解析失败（13:35）

报错：PowerShell 5.1 不识别字符串里的 `&&`，导致整个脚本 parse 失败。

修复（已写入）：
- 第 65 行：`&&` → `;`（bash 也支持 `;`）
- 第 66-69 行：把 `-Argument` 拆成独立变量 `$argument`，避免引号嵌套解析问题

### 真正的 root cause（13:37）

K 重跑后还是报同样错误（虽然位置略有变化）。继续诊断。

**真正的 root cause：UTF-8 BOM 缺失**。
- PowerShell 5.1 解析 UTF-8 文件必须有 BOM，否则按系统代码页解析
- 文件里有中文（`→`、`✗`、路径等），无 BOM → 中文乱码 → 整个脚本 parse 失败
- 之前的 `&&`、`$argument` 改动是无关噪音

修复（已应用）：
- 给所有 4 个 .ps1 加 UTF-8 BOM（用 bash `printf '\xef\xbb\xbf'` 前置 + cat）
- `install-autosync.ps1`、`sync.ps1`、`install-alias.ps1`、`auto-watch.ps1`

**注意**：以后我用 Write 工具写 .ps1 文件，要主动加 BOM 或者改用其他方式（避免每次 K 跑都要修一次）。
