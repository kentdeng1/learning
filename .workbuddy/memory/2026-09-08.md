## C 函数指针讲解(补 C 核心机制)

K 自问自答式提问:"函数指针 = 传函数入口地址?工程上用在接口分层解耦?"——理解方向对,做了精度补全。

讲解要点:
- 精度补全:函数名在表达式中退化为入口地址,`f` / `&f` / `*f` 等价,`fp()` 与 `(*fp)()` 等价
- 两种工程模式必须区分:
  - **回调 callback** = 控制反转(IoC),上层把函数交给下层,下层决定何时调用
  - **ops 接口表 / vtable** = C 的多态,上层持有函数指针表,运行时选实现
- 加分细节:HAL 传统 `HAL_UART_RxCpltCallback` 是 `__weak` 覆盖机制,**不是**函数指针;新版 `HAL_UART_RegisterCallback()` 才是
- 坑:NULL 调用 = HardFault、间接调用无法内联(ISR/高频路径慎用)、const 表放 Flash、类型严格匹配

产出:
- demo `code/funcptr_demo.c`(gcc 编译运行已验证):地址等价、回调注册、ops 表切换 HW/SW I2C、命令跳转表
- 关联:可与 `notes/c-bitfield-macro-cheatsheet.md` 合并为 C 核心机制速查
