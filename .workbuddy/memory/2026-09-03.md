## C 语言补强:宏双重求值(MAX x++ 陷阱)

K 问 `#define MAX(a,b)` 传 `MAX(x++,y++)` 如何避免某值 ++ 两次。

讲解要点:
- 根因:宏文本替换,参数出现 N 次即求值 N 次;MAX 中胜者参数比较 1 次 + 分支 1 次 = ++ 两次
- 解法三档:① GCC 语句表达式 + `__typeof__`(armclang/AC6 可用,AC5/C51 不可)② static inline(标准 C,类型写死)③ 调用方约定不传副作用实参(8051 生态现实解)
- demo: `code/max_macro_demo.c`(gcc 编译运行已验证)
