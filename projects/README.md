# 项目实战

简历要写的 2-3 个完整项目。**这是求职准备里最重要的一部分**。

## 推荐项目

按优先级排：

### 1. ⭐ 基于 FreeRTOS 的智能传感器节点
- 多个传感器采集（温湿度、光照、运动）
- MQTT 上报到云端
- 低功耗设计（电池供电，睡眠唤醒）
- **直接命中 JD 2 / JD 4 / JD 5 的核心要求**

### 2. 外设驱动库（含 ring buffer）
- UART / SPI / I2C 驱动层实现
- 不调 HAL，自己写
- 含 ring buffer、错误处理
- **直接命中"驱动开发"加分项**

### 3. （可选）其他
- 智能家居控制板
- BLE 蓝牙应用
- 物联网网关

## 每个项目的结构

```
project-name/
├── src/            # 源代码
├── inc/            # 头文件
├── docs/           # 设计文档
│   ├── architecture.md   # 架构图
│   └── design-notes.md   # 关键设计决策
├── README.md       # 项目介绍（**面试前必看**）
├── demo video      # 或 GIF（可选）
└── .gitignore      # 排除编译产物
```

## 关键

每个项目都要能**讲清楚**：
1. 解决了什么问题
2. 架构怎么设计的
3. 踩过什么坑、怎么解决的
4. 用 STAR 法则（Situation/Task/Action/Result）准备 5 分钟讲解
